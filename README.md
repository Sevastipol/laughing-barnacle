A chrome extension which embeds an AI chatbot (OpenAI 4.1) into the current webpage you are visiting by using Ctrl + A. Has many features such as: Unlimited Chats, Voice-to-Prompt support, File Attachment capabilities, Previous Chat History.

Originally made as a passion project that I could use in school to assist me with understanding text-heavy online resources in social studies, but was then submitted to Flavortown.

Get the extension here: https://chromewebstore.google.com/detail/website-ai/ejnepppmidppcmfpibdmbhmkkihcifjc
